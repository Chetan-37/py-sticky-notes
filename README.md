# Python Sticky Notes for Xubuntu

A lightweight, Windows-style Sticky Notes desktop application built with Python and PyQt5.

## Features
- Rich text formatting (Bold, Italic, Underline, Strikethrough, Bullet Lists)
- Customizable font sizes per note
- Always-on-top window pin
- Color themes & persistent auto-saving
- All-notes list & search hub

## How to Run
```bash
pip install PyQt5
python3 sticky.py
